# Capturas de Tela do Fluxo de Automação (n8n)

Coloque aqui os prints da automação conforme solicitado no Item 7 do regulamento:

1. `01-fluxo-completo.png`: Captura de tela mostrando todos os nodes conectados e a estrutura geral da automação.
2. `02-execucao-sucesso.png`: Print de uma execução concluída com sucesso (status verde/executado).
3. `03-config-webhook.png`: Print das configurações internas do nó de Webhook.
4. `04-config-normalizar.png`: Print das configurações do nó Edit Fields (Normalizar Dados).
5. `05-config-http-request.png`: Print das configurações do nó HTTP Request (Chamar API Express).
6. `06-config-switch.png`: Print das regras de roteamento por prioridade (Switch).
7. `07-config-sla.png`: Print dos nós de definição de SLA (Crítico e Padrão).
8. `08-config-respond.png`: Print do nó Respond to Webhook com o payload JSON formatado.
9. `09-resultado-execucao.png`: Print detalhado demonstrando os dados recebidos e processados em cada etapa.
