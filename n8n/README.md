# 📁 Fluxos de Automação do n8n

Para fins **estritamente didáticos e de conformidade com o desafio**, disponibilizamos duas versões do fluxo:

1. **`01-workflow-para-importar.json` (Template Limpo para Importação):**
   - Arquivo otimizado e formatado para que qualquer pessoa ou avaliador possa importar facilmente em uma nova instância do n8n (*Workflows > Import from File*).
   - Contém instruções no Sticky Note e nós pré-configurados.

2. **`02-workflow-exportado-producao.json` (Exportação Direta da Instância Dokploy):**
   - Cópia bruta exportada diretamente da nossa instância ativa no Dokploy (`https://n8n.dmedia.com.br`).
   - Contém os identificadores reais de execução, tags e metadados gerados pelo n8n em produção.

*(O arquivo `workflow_triagem_ia.json` é mantido como espelho para compatibilidade com o Docker Compose).*
